# BiS Memories

Takes a screenshot when something worth remembering happens, and keeps a note of what it was.

`/bism` (the old `/memories` still works) — part of the BiS addon family. Talks to the other BiS addons over the shared BiS channel
(`/biscomm` shows it, `/biscomm off` silences it).

### Older Forever memories

Forever memories now use the character's full name instead of the changing layer. To reunite older
memories and progress, log in on the character and use `/bism claim` to list matching old keys,
then `/bism claim <number>` to claim one. Review each key carefully: old keys saved only the first
name, so two characters with the same first name may have shared a key and cannot be separated
automatically. Unclaimed memories remain in the account album. The old progress book is retained.
